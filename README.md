# Customer Churn Prediction – Telecom

## 📌 Project Overview
This project focuses on predicting customer churn in the telecom industry using machine learning techniques. Customer churn prediction helps telecom companies identify customers who are likely to discontinue services and take preventive actions to improve retention.

---

## 📊 Dataset
- The dataset contains customer information such as demographics, services subscribed, tenure, monthly charges, and total charges.
- Target variable: **Churn** (Yes/No)
- Dataset is stored in the `data/` folder.
